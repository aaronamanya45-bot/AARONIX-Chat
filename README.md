# AARONIX Chat

A real-time chat application inspired by WhatsApp, built with React, Vite, Material UI, and Firebase.

## Features (Current Progress)
- User authentication (Email/Password).
- Custom usernames for searching.
- Real-time 1-on-1 private messaging.
- Responsive design (mobile-friendly layout).
- Dark theme with Material UI.

## Upcoming Features
- Phone number authentication (SMS).
- Audio and video calls (WebRTC).
- Media sharing (images/voice notes).

## Technologies Used
- React (Vite)
- Material UI
- Firebase (Authentication & Firestore Database)

## How to Run Locally
1. Clone the repository:
   git clone https://github.com/aaronamanya45-bot/aaronix-chat.git
   cd aaronix-chat

2. Install dependencies:
   npm install

3. Create a `.env` file in the root directory and add your Firebase configuration:
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   VITE_FIREBASE_APP_ID=your_app_id

4. Start the development server:
   npm run dev
